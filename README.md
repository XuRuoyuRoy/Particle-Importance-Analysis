# Particle-Importance-Analysis
A Fast Localization Method Under Indeterminate Magnetic Sources

Run PIA.m in MATLAB to see the results of Particle Importance Analysis. 
Modify the following parameters according to your requirements:
- Set flag_ia=1 to see the results of particle importance analysis
- Set flag_opt=1 to see the results of optimization based method
- Set flag_fig_in as 1, 2, or 3 to test different trajectory
